Статична сторінка: діти співробітників «телефонують» святому Миколаю. Це демо інтерфейсу, розмова поки що йде за сценарієм.

## Запуск

Збірка не потрібна.

```bash
npx serve .
# або
python3 -m http.server 8080
```

Трясіння телефоном працює лише через HTTPS, тому перевіряйте його на розгорнутій версії.

## Розгортання

Проєкт підключено до Vercel. Кожен коміт у `main` публікується автоматично. Framework preset: Other, без build command.

## Сценарій

1. **Анкета для батьків**: ім'я та прізвище (обов'язково), вік, захоплення.
2. **Потряси кулю**: дитина трясе кулю мишкою, пальцем або телефоном, шкала «Магія» заповнюється. Є кнопка «Почати без трясіння».
3. **Розмова з Миколаєм**: мікрофон, чат, субтитри, завершити.
4. **Листівка для батьків**: тривалість, вік, захоплення, бажання.

## Точки інтеграції

Уся логіка лежить у тезі `<script>` наприкінці `index.html`.

- `goShake(first, likes)` викликається після надсилання форми `#form`.
- `setMagic(0…1)` оновлює шкалу, `enter()` запускає перехід до розмови.
- `askMotion()` запитує дозвіл на датчик руху (iOS).
- `startCall(first, likes)` показує готові репліки. Тут підключається голосовий ШІ. Статус: `#nstat`, субтитри: `#capt`, чат: `addMsg(who, cls, text)`.
- `showPostcard(first, likes, time, age)` малює листівку. Надсилання листа треба зробити на сервері.

## Що ще не готово

- Немає справжнього голосу, розпізнавання мови та ШІ.
- Лист батькам не надсилається, адреса пошти не збирається.
- Мобільну версію і трясіння телефоном треба перевірити на реальних пристроях.
- Дві кулі з перемикачем залишено для порівняння.
- Sigma Sans не має кирилиці, український текст набрано шрифтом Roboto.

Кольорові смужки та льодяник у шкалі «Магія» адаптовано з Peppermint Range Slider (Jon Kantner, CodePen).
